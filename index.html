U1 Argus Remote RFID

Browser-based installer for ESP32-C3 single-reader and ESP32-S3 dual-reader OpenSpool and QIDI RFID hardware for Snapmaker U1.
Choose your controller and flash its current release. Connect the ESP32 by USB, select a release if needed, and install the firmware that belongs to your hardware variant.
Single Reader

ESP32-C3 Super Mini

firmware/ESP32-C3/V2.2/U1_Argus_Remote_RFID_ESP32-C3_V2_2.ino.merged.bin
  • One PN532 reader connected to the ESP32-C3
  • The newest available C3 release is selected by default
  • V2.2 prevents tag updates once filament is detected at the assigned Tool Head
  • Includes preferred BSSID selection for multi-access-point Wi-Fi installations
Dual Reader

ESP32-S3 N16R8

firmware/ESP32-S3/V1.2/U1_Argus_Remote_RFID_ESP32-S3_N16R8_V1_2.ino.merged.bin
  • Two local PN532 readers for left and right spool positions
  • The newest available S3 release is selected by default
  • V1.2 pauses each loaded spool reader and blocks accidental filament metadata updates
  • Includes BSSID/RSSI visibility and saved additional-reader Tool Head assignments
  • Includes preferred BSSID selection and the dedicated NFC task

Before Flashing

  • Use an ESP32-C3 with one PN532 or an ESP32-S3 N16R8 with two PN532 modules, all in HSU mode
  • Both hardware variants connect to 2.4 GHz Wi-Fi only
  • Snapmaker U1 with paxx12 Extended Firmware and external filament detection enabled
  • Chrome or Edge and a data-capable USB cable
After flashing Connect to the hotspot U1-Argus-Setup-XXXX. The captive portal should open automatically. If not, open http://192.168.4.1.

If the board is not detected immediately, reconnect it and try again. Some boards may require BOOT to be held while connecting.
