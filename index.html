U1 Argus Remote RFID

Fast browser-based installer for the V1.3 release of the ESP32-C3 Super Mini + PN532 OpenSpool remote RFID reader for Snapmaker U1.
Schneller browserbasierter Installer fuer das V1.3-Release des ESP32-C3 Super Mini + PN532 OpenSpool Remote RFID Readers fuer den Snapmaker U1.
One firmware, one job, one clean setup. Connect your ESP32-C3 by USB, click Install, and flash the current public V1.3 release directly from the browser.
Eine Firmware, eine Aufgabe, ein sauberer Setup-Weg. ESP32-C3 per USB anschliessen, auf Install klicken und das aktuelle oeffentliche V1.3-Release direkt im Browser flashen.

Aktuelles oeffentliches Release

V1.3

ESP32-C3 Super Mini

Update Install - keep settings

Update Install - Einstellungen behalten

Use this for normal U1 Argus updates. It does not write the NVS settings area and keeps Wi-Fi, printer, language, Tool Head, and reader settings.

Fuer normale U1-Argus-Updates verwenden. Der NVS-Einstellungsbereich wird nicht geschrieben. WLAN, Drucker, Sprache, Tool Head und Reader-Einstellungen bleiben erhalten.

Clean Install - reset settings

Clean Install - Einstellungen zuruecksetzen

Use this for a first flash or a board with unrelated firmware. It writes the complete merged image from offset 0 and resets stored settings.

Fuer den ersten Flash oder ein Board mit anderer Firmware verwenden. Es wird das komplette merged Image ab Offset 0 geschrieben und gespeicherte Einstellungen werden zurueckgesetzt.

  • Update Install writes boot metadata and the app image without touching the NVS settings area
  • Clean Install uses firmware/V1.3/U1_Argus_Remote_RFID_V1.3.ino.merged.bin
  • Best used with Chrome or Edge and a data-capable USB cable
  • Update Install schreibt Boot-Metadaten und die App, ohne den NVS-Einstellungsbereich anzufassen
  • Clean Install verwendet firmware/V1.3/U1_Argus_Remote_RFID_V1.3.ino.merged.bin
  • Am besten mit Chrome oder Edge und einem datenfaehigen USB-Kabel verwenden
Which one should I choose? If U1 Argus is already installed, choose Update Install and do not enable Erase device. If the board has other firmware, choose Clean Install and allow erase/clear flash when prompted.
Welche Variante soll ich nehmen? Wenn U1 Argus bereits installiert ist, Update Install waehlen und Erase device nicht aktivieren. Wenn auf dem Board andere Firmware ist, Clean Install waehlen und Erase/Clear Flash bestaetigen, wenn der Installer danach fragt.

What You Need Before Flashing

Was Du Vor Dem Flashen Brauchst

  • ESP32-C3 Super Mini
  • PN532 in HSU mode
  • 4 connection wires
  • Snapmaker U1 with paxx12 Extended Firmware and external filament detection enabled
  • ESP32-C3 Super Mini
  • PN532 im HSU-Modus
  • 4 Verbindungskabel
  • Snapmaker U1 mit paxx12 Extended Firmware und aktivierter externer Filament Detection
After flashing Connect to the hotspot U1-Argus-Setup-XXXX. The captive portal should open automatically. If not, open http://192.168.4.1.
Nach dem Flashen Mit dem Hotspot U1-Argus-Setup-XXXX verbinden. Das Captive Portal sollte automatisch starten. Falls nicht, http://192.168.4.1 oeffnen.

If the board is not detected immediately, reconnect it and try again. Some boards may require BOOT to be held while connecting.
